# UI/UX audit — newest features + card-model removal (2026-09-25)

Peter's request: "flesh out some of the newest features … UI/UX audit for the
new features and the card bg removal. Multiple agents. Try to catch with
screenshots too. For example I have some problems with the spacing between
the calendar day number and the full bg event."

Method: seeded preview DB (7 labels incl. a project + a group, ~24 events
incl. overlapping/all-day/multi-day, ~10 tasks, 4 habits with 90 days of
history, 4 contacts), live server, four parallel auditor agents driving real
headless Chromium at 1440 / 900 / 390px, light + dark, with
getBoundingClientRect / computed-style / WCAG-ratio measurements behind every
claim. Screenshots lived in the session scratchpad (not committed — ~40 MB).
Two findings were spot-checked by the lead against their screenshots (H-01
"all done" after one +1, C-10 overflow-as-toast) and hold.

Severity: P1 = clearly wrong / broken for a real use; P2 = polish. No P0s.
